# Nestbook
Egy egyszerű, gyors, és moduláris internetes vendégkönyv rendszer melyen keresztül a felhasználók létrehozhatják és személyre szabhatják saját vendégkönyveiket, azok tartalmát moderálhatják. A könyvek más weboldalakba is könnyen beilleszthetőek, így egyfajta komment részlegként is funkcionálhatnak.
